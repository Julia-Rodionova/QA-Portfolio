# API Testing

В этом разделе представлены примеры тестирования REST API
с использованием Postman.

## Практика

- GET, POST, PUT и DELETE-запросы;
- проверка HTTP-статусов;
- проверка тела ответа;
- работа с JSON;
- позитивные и негативные сценарии;
- авторизация;
- работа с токенами;
- переменные окружения;
- Postman Tests.

## Инструменты

- Postman
- REST API
- HTTP
- JSON
