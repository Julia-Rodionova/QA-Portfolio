# Postman Collection

В этом разделе размещена коллекция Postman
с примерами тестирования REST API.

Коллекция включает запросы для:

- регистрации и авторизации;
- получения данных;
- создания данных;
- изменения данных;
- удаления данных.

Также используются:

- environment variables;
- token;
- Postman Tests;
- проверки HTTP-статусов;
- проверки JSON-ответов.
