# SQL

В этом разделе представлены примеры SQL-запросов,
которые использовались в учебной практике.

## Практика

- SELECT;
- WHERE;
- ORDER BY;
- GROUP BY;
- JOIN;
- INSERT;
- UPDATE;
- DELETE;
- работа с первичными и внешними ключами;
- проверка корректности данных.

## Инструменты

- PostgreSQL
- DBeaver
