## 🌍 EU-Relocate — Web Testing

Ручное тестирование веб-приложения **EU-Relocate**.

Проект охватывает полный цикл практической работы Manual QA:

**анализ требований → разработка тест-кейсов → выполнение тестирования → регистрация дефектов → анализ обратной связи → Retest → Regression Testing.**

В рамках проекта выполнялись:

- анализ требований;
- разработка и выполнение тест-кейсов;
- функциональное тестирование;
- позитивное и негативное тестирование;
- UI-тестирование;
- тестирование форм и валидации;
- тестирование навигации;
- проверка бизнес-логики квиза;
- регистрация баг-репортов;
- анализ отклонённых дефектов;
- повторное тестирование;
- регрессионное тестирование.

### 📊 Результаты

| Метрика | Результат |
|---|---:|
| Тест-кейсов | **49** |
| Главная страница | **31** |
| Страница «Подобрать страну» | **18** |
| Баг-репортов отобрано для портфолио | **6** |
| Повторно проверено баг-репортов | **38** |
| Закрыто | **25** |
| Переоткрыто | **3** |
| Открыто | **9** |
| Отклонено | **1** |

В проекте представлены требования, тест-кейсы в Markdown и Excel, баг-репорты, видеозапись воспроизведения дефекта и результаты Retest & Regression.

➡️ [Подробнее о проекте EU-Relocate](Web-Testing/EU-Relocate/)
