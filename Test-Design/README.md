# Test Design

В этом разделе представлены примеры применения
техник тест-дизайна.

## Используемые техники

- эквивалентное разбиение;
- анализ граничных значений;
- позитивные сценарии;
- негативные сценарии.

Цель применения техник тест-дизайна —
получить эффективный набор проверок и уменьшить
количество избыточных тестов.
