# Hitch — Web Testing

Учебный проект по ручному тестированию веб-приложения Hitch.

Hitch — веб-сервис для поиска сотрудников и размещения анкет кандидатов. В приложении предусмотрены регистрация физических и юридических лиц, работа с анкетами, поиск кандидатов и компаний, а также работа с предложениями.

## 🎯 Цель тестирования

Проверить функциональность веб-приложения, выявить и документировать критические дефекты до релиза.

Период тестирования: **16.09–11.10.2025**.

Все проверки выполнялись вручную, без использования средств автоматизации.

## 👥 Роли пользователей

В приложении предусмотрены:

- незарегистрированный пользователь;
- кандидат (B2C);
- компания (B2B).

## 🔍 Протестированная функциональность

В рамках проекта были проверены:

- регистрация физического лица;
- регистрация юридического лица;
- авторизация физического лица;
- авторизация юридического лица;
- личный кабинет кандидата;
- личный кабинет компании;
- форма «Новая заявка»;
- главная страница сайта.

## 📝 Тест-кейсы

Для проекта подготовлено **154 тест-кейса**.

Тест-кейсы охватывают основные функциональные области веб-приложения, включая регистрацию, авторизацию, личные кабинеты, работу с заявками и главную страницу.

## 📊 Результаты тестирования

По итогам тестирования:

| Метрика | Результат |
|---|---:|
| Тест-кейсов | 154 |
| Выполнение тест-кейсов | 98% |
| Успешное прохождение тест-кейсов | 77% |
| Покрытие требований тест-кейсами | 100% |
| Найдено дефектов | 63 |
| Исправлено дефектов | 22 |
| Устранение дефектов | 35% |

Наибольшее количество дефектов было обнаружено в модуле **«Личный кабинет»**.

По результатам тестирования продукт не был рекомендован к выпуску до исправления оставшихся дефектов с приоритетом «Важно».
