# Hitch — Web Testing

Учебный проект по ручному тестированию веб-сервиса Hitch.

Hitch предназначен для поиска сотрудников, размещения анкет кандидатов
и взаимодействия кандидатов с компаниями.

## 🎯 Цель тестирования

Проверить соответствие веб-приложения функциональным требованиям,
корректность основных пользовательских сценариев и работу интерфейса.

## 👥 Роли пользователей

В приложении предусмотрены:

- незарегистрированный пользователь;
- кандидат (B2C);
- компания (B2B).

## 🔍 Основные области тестирования

### Регистрация и авторизация

Проверка:

- регистрации кандидата;
- регистрации компании;
- обязательных полей;
- email;
- телефона;
- ОГРН;
- пароля и подтверждения пароля;
- согласия на обработку персональных данных;
- авторизации B2C и B2B.

### Личный кабинет кандидата

Проверка:

- заполнения анкеты;
- Ф. И. О.;
- телефона;
- информации «О себе»;
- направления;
- статуса;
- занимаемой должности;
- социальных сетей;
- сохранения данных.

### Личный кабинет компании

Проверка:

- анкеты компании;
- контактных данных;
- описания деятельности;
- направления;
- поиска сотрудников;
- просмотра анкет кандидатов.

### Поиск

Проверка:

- списка кандидатов;
- фильтра по направлению;
- фильтра по статусу;
- списка компаний;
- фильтра компаний по направлению.

### Предложения

Проверка:

- отправки предложения кандидату;
- описания предложения;
- предлагаемой зарплаты;
- получения предложения кандидатом;
- принятия предложения;
- отклонения предложения;
- изменения статуса предложения;
- отображения контактов после принятия предложения.

## 🧪 Виды тестирования

В рамках проекта применялись:

- функциональное тестирование;
- позитивное тестирование;
- негативное тестирование;
- UI-тестирование;
- исследовательское тестирование;
- проверка валидации полей.

## 📋 Тестовая документация
