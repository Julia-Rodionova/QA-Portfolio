# Hitch — Web Testing

Учебный проект по ручному тестированию веб-сервиса Hitch.

Hitch — веб-сервис для поиска сотрудников и размещения анкет кандидатов.
Сервис предусматривает регистрацию физических и юридических лиц,
работу с анкетами, поиск кандидатов и компаний, а также отправку
и обработку предложений.

## 🎯 Цель проекта

Провести тестирование веб-приложения на основе требований и проверить
корректность основных пользовательских сценариев.

## 👥 Роли пользователей

В приложении предусмотрены три основные роли:

- незарегистрированный пользователь;
- кандидат (B2C);
- компания (B2B).

## 🔍 Тестируемая функциональность

### Регистрация

Проверка регистрации:

- кандидата (B2C);
- компании (B2B);
- обязательных полей;
- email;
- телефона;
- ОГРН;
- пароля;
- подтверждения пароля;
- согласия на обработку персональных данных.

### Авторизация

Проверка:

- авторизации кандидата по email и паролю;
- авторизации компании по ОГРН и паролю;
- валидации данных формы.

### Личный кабинет кандидата

Проверка:

- заполнения и сохранения анкеты;
- Ф. И. О.;
- телефона;
- информации «О себе»;
- направления;
- статуса;
- занимаемой должности;
- социальных сетей;
- просмотра компаний;
- просмотра входящих предложений.

### Личный кабинет компании

Проверка:

- заполнения анкеты компании;
- контактных данных;
- описания деятельности;
- направления;
- поиска сотрудников;
- просмотра анкет кандидатов;
- отправленных предложений.

### Поиск

Проверка:

- списка кандидатов;
- фильтрации кандидатов по направлению;
- фильтрации кандидатов по статусу;
- списка компаний;
- фильтрации компаний по направлению.

### Предложения

Проверка:

- отправки предложения кандидату;
- описания предложения;
- предлагаемой зарплаты;
- получения предложения кандидатом;
- принятия предложения;
- отклонения предложения;
- изменения статуса предложения;
- отображения контактов кандидата после принятия предложения.

## 🧪 Виды тестирования
