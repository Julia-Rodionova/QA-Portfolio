# Test Report — Hitch

Итоговый отчёт по ручному тестированию веб-приложения Hitch.

## 🎯 Цель тестирования

Проверить функциональность приложения, выявить и документировать критические дефекты до релиза.

Период тестирования: **16.09–11.10.2025**.

Все проверки выполнялись вручную.

## 🧪 Проведённое тестирование

- функциональное тестирование;
- тестирование совместимости;
- Usability-тестирование.

Проверялись:

- регистрация физического и юридического лица;
- авторизация физического и юридического лица;
- личный кабинет кандидата;
- личный кабинет компании;
- форма «Новая заявка»;
- главная страница.

## 📊 Результаты

| Метрика | Результат |
|---|---:|
| Тест-кейсов | 154 |
| Выполнение тест-кейсов | 98% |
| Успешное прохождение | 77% |
| Покрытие требований | 100% |
| Найдено дефектов | 63 |
| Исправлено дефектов | 22 |
| Устранение дефектов | 35% |

Наибольшее количество дефектов было обнаружено в модуле **«Личный кабинет»**.

## 🚦 Решение о релизе

По результатам тестирования продукт не рекомендован к выпуску до исправления оставшихся дефектов с приоритетом «Важно».
