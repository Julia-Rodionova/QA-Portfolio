# Hitch — Web Testing

Учебный проект по ручному тестированию веб-приложения Hitch.

Hitch — веб-сервис для поиска сотрудников и размещения анкет кандидатов. В приложении предусмотрены регистрация физических и юридических лиц, работа с анкетами, поиск кандидатов и компаний, а также работа с предложениями.

## 🎯 Цель тестирования

Проверить функциональность веб-приложения, выявить и документировать критические дефекты до релиза.

**Период тестирования: 01.10–20.11.2025**

Все проверки выполнялись вручную, без использования средств автоматизации.

## 👥 Роли пользователей

В приложении предусмотрены:

- незарегистрированный пользователь;
- кандидат (B2C);
- компания (B2B).

## 🔍 Протестированная функциональность

В рамках проекта были проверены:

- регистрация физического лица;
- регистрация юридического лица;
- авторизация физического лица;
- авторизация юридического лица;
- личный кабинет кандидата;
- личный кабинет компании;
- форма «Новая заявка»;
- главная страница сайта.

## 🧪 Виды тестирования
