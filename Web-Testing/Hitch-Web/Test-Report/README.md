# Test Report — Hitch

Итоговый отчёт по результатам ручного тестирования веб-приложения Hitch.

## 🎯 Цель тестирования

Проверить функциональность приложения, выявить и документировать критические дефекты до релиза.

**Период тестирования: 01.10–20.11.2025**

**Дата составления отчёта: 20.11.2025**

Все проверки выполнялись вручную, без использования средств автоматизации.

## 🧪 Проведённое тестирование

В рамках проекта проводились:

- функциональное тестирование;
- тестирование совместимости;
- Usability-тестирование.

Проверялись следующие функциональные области:

- регистрация физического лица;
- регистрация юридического лица;
- авторизация физического лица;
- авторизация юридического лица;
- личный кабинет кандидата;
- личный кабинет компании;
- форма «Новая заявка»;
- главная страница сайта.

## 📊 Результаты тестирования

| Метрика | Результат |
|---|---:|
| Тест-кейсов | 154 |
| Выполнение тест-кейсов | 98% |
| Успешное прохождение тест-кейсов | 77% |
| Покрытие требований тест-кейсами | 100% |
| Найдено дефектов | 63 |
| Исправлено дефектов | 22 |
| Устранение дефектов | 35% |

Наибольшее количество дефектов было обнаружено в модуле **«Личный кабинет»**.

## 🚦 Вывод по результатам тестирования

Метрики успешного прохождения тест-кейсов, выполнения тест-кейсов и покрытия требований находятся в зелёной зоне.

Метрика устранения дефектов находится в красной зоне.

Продукт **не рекомендован к выпуску** до исправления оставшихся дефектов с приоритетом «Важно».

Дефекты с приоритетами «Нормально» и «Неважно» могут быть исправлены после релиза.

## 💡 Рекомендации

По результатам тестирования были сформированы рекомендации:

- уделить особое внимание исправлению найденных дефектов;
- изменить название кнопки в форме «Обсудить сотрудничество» на «Отправить»;
- сделать карточки кандидатов и компаний адаптивными.
