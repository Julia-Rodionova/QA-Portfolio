# BUG-006 — Некликабельна кнопка «Отправить заявку» при выборе анкеты кандидата с частичной занятостью

**YouGile ID:** ETA-70  
**Модуль:** Личный кабинет компании / Поиск сотрудников  
**Тип:** Функциональный / Навигация  
**Приоритет:** High / Высокий  
**Статус:** Closed / Закрыт  

## 🌐 Окружение

- **Платформа:** Web
- **Браузеры:** Google Chrome, Yandex Browser

## 📋 Предусловия

1. Открыть сайт Hitch.
2. Авторизоваться под учётной записью компании.
3. Открыть карточку кандидата.

## 🔄 Шаги воспроизведения

1. В личном кабинете компании в разделе «Поиск сотрудников» выбрать анкету кандидата с частичной занятостью и перейти в анкету.
2. В анкете кандидата нажать кнопку «Отправить заявку».

## ❌ Фактический результат

Кнопка «Отправить заявку» некликабельна.

## ✅ Ожидаемый результат

При нажатии на кнопку «Отправить заявку» осуществляется переход на форму «Новая заявка».

## 📎 Источник

Дефект зарегистрирован в YouGile под ID **ETA-70** в рамках ручного тестирования веб-приложения Hitch.
