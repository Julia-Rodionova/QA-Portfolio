# BUG-002 — Изменение кнопки «Зарегистрироваться» при увеличении масштаба страницы

**YouGile ID:** ETA-16  
**Модуль:** Регистрация частного лица  
**Тип:** UI / Масштабирование  
**Приоритет:** Medium / Средний  
**Статус:** Reopened / Переоткрыт  

## 🌐 Окружение

- **Платформа:** Web
- **Браузеры:** Google Chrome, Yandex Browser

## 📋 Предусловия

1. Открыть сайт Hitch.
2. Нажать кнопку «Войти» в навигационном меню.
3. Нажать ссылку «Зарегистрируйтесь» в форме авторизации.

## 🔄 Шаги воспроизведения

1. Увеличить масштаб страницы.
2. Обратить внимание на кнопку «Зарегистрироваться».

## ❌ Фактический результат

При увеличении масштаба страницы изменяется кнопка «Зарегистрироваться».

## ✅ Ожидаемый результат

При увеличении масштаба страницы кнопка «Зарегистрироваться» не изменяется.

Дефект зарегистрирован в YouGile под ID **ETA-16** в рамках ручного тестирования веб-приложения Hitch.
