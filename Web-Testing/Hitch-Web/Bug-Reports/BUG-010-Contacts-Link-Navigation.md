# BUG-010 — Открывается главная страница сайта при переходе по ссылкам в блоке «Контакты»

**YouGile ID:** ETA-95  
**Модуль:** Главная страница / Контакты  
**Тип:** Функциональный / Навигация  
**Приоритет:** High / Высокий  
**Статус:** Open / Открыт  

## 🌐 Окружение

- **Платформа:** Web / Mobile
- **Устройство:** TECNO POVA 6
- **Дополнительно:** Chrome DevTools Device Toolbar

## 📋 Предусловия

1. На мобильном устройстве или через Chrome DevTools Device Toolbar открыть сайт Hitch.
2. Пользователь не авторизован.

## 🔄 Шаги воспроизведения

1. Прокрутить главную страницу до блока «Контакты».
2. Нажать ссылку «Обсудить сотрудничество».

## ❌ Фактический результат

В новой вкладке открывается главная страница сайта.

## ✅ Ожидаемый результат

Ссылка ведёт на соответствующий документ.

Дефект зарегистрирован в YouGile под ID **ETA-95** в рамках ручного тестирования веб-приложения Hitch.
