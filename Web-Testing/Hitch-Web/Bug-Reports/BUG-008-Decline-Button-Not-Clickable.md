# BUG-008 — Некликабельна кнопка «Отказаться» в форме «Предложение»

**YouGile ID:** ETA-72  
**Модуль:** Личный кабинет кандидата / Предложения  
**Тип:** Функциональный  
**Приоритет:** High / Высокий  
**Статус:** Closed / Закрыт  

## 🌐 Окружение

- **Платформа:** Web
- **Браузеры:** Google Chrome, Yandex Browser

## 📋 Предусловия

1. Открыть сайт Hitch.
2. Авторизоваться под учётной записью кандидата.
3. Получить предложение от компании.

## 🔄 Шаги воспроизведения

1. В личном кабинете кандидата перейти в раздел «Предложения».
2. Выбрать компанию и перейти в анкету.
3. В форме «Предложение» нажать кнопку «Отказаться».

## ❌ Фактический результат

Кнопка «Отказаться» некликабельна.

### 🎥 Видеодоказательство

[▶️ Посмотреть воспроизведение дефекта](Videos/BUG-008-Actual-Result.mp4)

## ✅ Ожидаемый результат

После нажатия кнопки «Отказаться» появляется сообщение об отказе от предложения.

## 📎 Источник

Дефект зарегистрирован в YouGile под ID **ETA-72** в рамках ручного тестирования веб-приложения Hitch.
