# BUG-005 — Ошибка валидации при вводе корректного значения в поле «Telegram»

**YouGile ID:** ETA-43  
**Модуль:** Личный кабинет кандидата / Анкета  
**Тип:** Функциональный / Валидация  
**Приоритет:** Medium / Средний  
**Статус:** Closed / Закрыт  

## 🌐 Окружение

- **Платформа:** Web
- **Браузеры:** Google Chrome, Yandex Browser

## 📋 Предусловия

1. Открыть сайт Hitch.
2. Нажать кнопку «Войти».
3. Ввести данные в форму авторизации частного лица.
4. Нажать кнопку «Войти».
5. Перейти в раздел «Мой кабинет».

## 🔄 Шаги воспроизведения

1. Ввести в поле «Telegram» корректное значение:

   `https://t.me/lyulchik_r`

## ❌ Фактический результат

Появляется сообщение:

> «Поле содержит значение некорректного формата».

Корректное значение Telegram не принимается системой.

<img src="Screenshots/BUG-005-Actual-Result.png" width="700" alt="Фактический результат — ошибка валидации поля Telegram">

## ✅ Ожидаемый результат

Поле «Telegram» принимает корректно введённое значение без отображения сообщения об ошибке валидации.

<img src="Screenshots/BUG-005-Expected-Result.png" width="700" alt="Ожидаемый результат — корректное поле Telegram">

Дефект зарегистрирован в YouGile под ID **ETA-43** в рамках ручного тестирования веб-приложения Hitch.
