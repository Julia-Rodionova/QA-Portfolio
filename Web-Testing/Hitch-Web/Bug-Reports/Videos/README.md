## 🐞 BUG-008 — Decline Button Not Clickable

**YouGile ID:** ETA-72

В форме «Предложение» кнопка **«Отказаться»** не реагирует на нажатие.

### ❌ Фактический результат

При нажатии на кнопку «Отказаться» действие не выполняется.

🎬 [Смотреть видео воспроизведения](BUG-008-Actual-Result.mp4)

### ✅ Ожидаемый результат

После нажатия на кнопку «Отказаться» должно отображаться сообщение об отказе от предложения.

➡️ [Открыть BUG-008](../BUG-008-Decline-Button-Not-Clickable.md)

## 🎯 Назначение видеозаписей

Видеозаписи используются для:

- демонстрации последовательности действий;
- подтверждения фактического поведения приложения;
- фиксации дефектов, которые удобнее показать в динамике;
- дополнения баг-репортов визуальными доказательствами;
- упрощения воспроизведения обнаруженных дефектов.
