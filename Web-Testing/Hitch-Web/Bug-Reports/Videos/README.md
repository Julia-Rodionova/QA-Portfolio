# 🎥 Videos — Bug Reports

В папке представлены видеозаписи, подтверждающие воспроизведение дефектов, обнаруженных в ходе ручного тестирования веб-приложения Hitch.

Видео используются как дополнительные доказательства фактического поведения приложения в случаях, когда дефект удобнее продемонстрировать в динамике.

## 📌 Назначение

Видеозаписи позволяют наглядно продемонстрировать:

- последовательность действий пользователя;
- воспроизведение дефекта;
- некорректную работу интерактивных элементов;
- фактическое поведение веб-приложения.

Каждая видеозапись связана с соответствующим баг-репортом в папке `Bug-Reports`.
