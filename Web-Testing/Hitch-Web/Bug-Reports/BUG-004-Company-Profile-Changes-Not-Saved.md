# BUG-004 — Не сохраняются изменения в анкете компании после обновления страницы

**YouGile ID:** ETA-66  
**Модуль:** Личный кабинет компании  
**Тип:** Функциональный / Сохранение данных  
**Приоритет:** High / Высокий  
**Статус:** Reopened / Переоткрыт  

## 🌐 Окружение

- **Платформа:** Web
- **Браузеры:** Google Chrome, Yandex Browser

## 📋 Предусловия

1. Открыть сайт Hitch.
2. Нажать кнопку «Войти».
3. Ввести данные в форму авторизации юридического лица.
4. Нажать кнопку «Войти».
5. Перейти в раздел «Мой кабинет».

## 🔄 Шаги воспроизведения

1. Внести изменения в анкету компании.
2. Обновить страницу.

## ❌ Фактический результат

Внесённые изменения не сохраняются после обновления страницы.

## ✅ Ожидаемый результат

Внесённые изменения сохраняются и отображаются после обновления страницы.

## 📎 Источник

Дефект зарегистрирован в YouGile под ID **ETA-66** в рамках ручного тестирования веб-приложения Hitch.
