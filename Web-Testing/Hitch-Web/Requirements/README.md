# 📄 Requirements — Hitch Web

В данном разделе представлены требования к веб-приложению **Hitch**, использованные в качестве основы для проведения ручного тестирования.

Требования определяют ожидаемое поведение системы и используются при разработке тестовой документации, выполнении проверок и оценке покрытия функциональности тестами.

---

## 📋 Документ с требованиями

[📄 Открыть Hitch Requirements](Hitch-Requirements.pdf)

Документ использовался в процессе тестирования для:

- анализа функциональности веб-приложения;
- определения объектов тестирования;
- выделения тестовых сценариев;
- разработки тест-кейсов;
- проведения позитивных и негативных проверок;
- определения ожидаемого поведения системы;
- построения матрицы трассировки;
- контроля покрытия требований тест-кейсами.

---

## 🔍 Основные функциональные области

В рамках проекта анализировались требования к следующим областям веб-приложения:

- регистрация физического лица;
- регистрация юридического лица;
- авторизация пользователей;
- личный кабинет кандидата;
- личный кабинет компании;
- работа с анкетами;
- поиск сотрудников;
- создание и отправка заявок;
- работа с предложениями;
- главная страница веб-приложения.

---

## 🧪 Использование требований при тестировании

Требования использовались как основа для определения:

- что необходимо протестировать;
- какое поведение системы является ожидаемым;
- какие позитивные сценарии необходимо проверить;
- какие негативные сценарии необходимо проверить;
- какие данные использовать при выполнении тестов;
- какие функциональные области должны быть покрыты тест-кейсами.

При обнаружении расхождения между фактическим поведением приложения и требованиями создавался баг-репорт.
