# Test Cases

Тест-кейсы, разработанные и выполненные в рамках ручного тестирования веб-приложения Hitch.

## Материалы

### Регрессионное тестирование

Набор тест-кейсов для проверки основной функциональности веб-приложения:

- регистрация;
- авторизация;
- личный кабинет кандидата;
- личный кабинет компании;
- работа с заявками.

### Главная страница

Набор тест-кейсов для проверки главной страницы веб-приложения.

Тест-кейсы входят в общий набор из 154 тест-кейсов проекта.

## Результаты

По итогам тестирования:

- выполнение тест-кейсов — 98%;
- успешное прохождение — 77%;
- покрытие требований тест-кейсами — 100%.
