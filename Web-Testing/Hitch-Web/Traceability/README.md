# Traceability Matrix — Hitch

Матрица трассировки требований и тест-кейсов, подготовленная в рамках ручного тестирования веб-приложения Hitch.

**Дата: 20.11.2025**

## 🎯 Назначение

Матрица трассировки использовалась для контроля покрытия требований тест-кейсами и отслеживания связи между требованиями и разработанными проверками.

В матрице:

- строки содержат требования;
- столбцы содержат номера тест-кейсов;
- зелёным цветом отмечены связи между требованиями и соответствующими тест-кейсами.

## 🔍 Покрываемая функциональность

Матрица включает требования и тест-кейсы для проверки:

- регистрации физического лица;
- регистрации юридического лица;
- авторизации физического лица;
- авторизации юридического лица;
- личного кабинета кандидата;
- личного кабинета компании;
- просмотра кандидатов и компаний;
- работы с заявками;
- главной страницы;
- навигационного меню;
- блоков кандидатов и компаний;
- формы «Обсудить сотрудничество»;
- футера;
- изменения масштаба;
- ссылок в формах.

## 📊 Покрытие требований

По результатам трассировки все требования имеют соответствующие тест-кейсы.

**Покрытие требований тест-кейсами — 100%.**

Данный показатель также использовался как одна из метрик в итоговом отчёте о тестировании.

## 📌 Что демонстрирует

Матрица трассировки демонстрирует навыки:

- работы с требованиями;
- сопоставления требований и тест-кейсов;
- анализа тестового покрытия;
- контроля полноты тестирования;
- работы с тестовой документацией.
