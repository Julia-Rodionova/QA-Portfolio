# Traceability Matrix

Матрица трассировки требований и тест-кейсов проекта Hitch.

## 🎯 Назначение

Матрица использовалась для контроля покрытия требований тест-кейсами и проверки связи между требованиями и разработанными проверками.

В матрице:

- строки содержат требования;
- столбцы содержат номера тест-кейсов;
- зелёным цветом отмечены связи между требованиями и соответствующими тест-кейсами.

## 📊 Результат

Покрытие требований тест-кейсами — **100%**.

Матрица охватывает функциональность:

- регистрации B2C и B2B;
- авторизации B2C и B2B;
- личного кабинета кандидата;
- личного кабинета компании;
- работы с заявками;
- главной страницы;
- навигации;
- кандидатов и компаний;
- формы обратной связи;
- футера;
- масштабирования;
- ссылок в формах.
