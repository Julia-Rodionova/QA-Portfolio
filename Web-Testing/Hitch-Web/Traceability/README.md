# Traceability Matrix — Hitch

Матрица трассировки требований и тест-кейсов, подготовленная в рамках ручного тестирования веб-приложения Hitch.

## 🎯 Назначение

Матрица использовалась для контроля покрытия требований тест-кейсами и отслеживания связи между требованиями и разработанными проверками.

В матрице:

- строки содержат требования;
- столбцы содержат номера тест-кейсов;
- зелёным цветом отмечены связи между требованиями и соответствующими тест-кейсами.

## 📊 Покрытие требований

По результатам анализа матрицы все требования имеют соответствующие тест-кейсы.

**Покрытие требований тест-кейсами — 100%.**

Матрица охватывает проверки:

- регистрации физического лица;
- регистрации юридического лица;
- авторизации физического лица;
- авторизации юридического лица;
- личного кабинета кандидата;
- личного кабинета компании;
- работы с заявками;
- главной страницы;
- навигационного меню;
- блоков кандидатов и компаний;
- формы «Обсудить сотрудничество»;
- футера;
- изменения масштаба;
- ссылок в формах.

## 📌 Что демонстрирует

Матрица демонстрирует практические навыки:

- работы с требованиями;
- трассировки требований и тест-кейсов;
- анализа тестового покрытия;
- контроля полноты тестирования;
- работы с тестовой документацией.
