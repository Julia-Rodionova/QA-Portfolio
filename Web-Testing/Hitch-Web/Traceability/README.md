# 🔗 Traceability Matrix — Hitch Web

В данном разделе представлена **матрица трассировки требований и тест-кейсов** веб-приложения **Hitch**.

Матрица использовалась для контроля покрытия требований тест-кейсами и проверки того, что каждое требование проекта было протестировано.

**Дата актуализации:** 20.11.2025.

---

## 📋 Материалы

Матрица представлена в двух форматах:

- [📄 Матрица трассировки — PDF](Матрица_трассировки_Hitch_20_ноября.pdf) — версия для просмотра;
- [📊 Матрица трассировки — XLSX](Матрица_трассировки_Hitch_20_ноября.xlsx) — рабочая версия с цветовыми обозначениями связей.

---

## 🔍 Структура матрицы

В матрице:

- **строки** соответствуют требованиям;
- **столбцы** соответствуют тест-кейсам;
- **зелёным цветом** отмечены связи между требованиями и соответствующими тест-кейсами.

Такой формат позволяет определить, какие требования покрыты тестами, и выявить возможные пробелы в тестовом покрытии.

---

## 📊 Покрытие требований

По итогам проекта:

**Покрытие требований тест-кейсами — 100%.**

Это означает, что все требования, включённые в матрицу трассировки, имеют соответствующее тестовое покрытие.

---

## 🎯 Назначение матрицы

Матрица трассировки использовалась для:

- контроля покрытия требований;
- связывания требований с тест-кейсами;
- проверки полноты тестовой документации;
- поиска требований без соответствующих тестов;
- контроля изменений тестового покрытия.
