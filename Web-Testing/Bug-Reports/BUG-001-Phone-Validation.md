# BUG-001 — Успешная регистрация при вводе 11 цифр в поле «Телефон»

**YouGile ID:** ETA-11  
**Модуль:** Регистрация физического лица  
**Тип:** Функциональный / Валидация  
**Приоритет:** High / Высокий
**Статус:** Исправлен

## 📋 Предусловия

1. Открыть сайт Hitch.
2. Нажать кнопку «Войти» в навигационном меню.
3. Нажать ссылку «Зарегистрируйтесь» в форме авторизации.

## 🔄 Шаги воспроизведения

1. Заполнить обязательные поля формы следующими значениями:

   - **ФИО:** Иванов Александр Сергеевич
   - **Почта:** test@ya.ru
   - **Телефон:** +790345678985
   - **Пароль:** 1245ABCD
   - **Повторите пароль:** 1245ABCD

2. Нажать кнопку «Зарегистрироваться».

## ❌ Фактический результат

Появляется сообщение:

> «Регистрация прошла успешно»

После успешной регистрации происходит переход на форму авторизации.

Система принимает номер телефона, содержащий 11 цифр вместо допустимых 10, и позволяет завершить регистрацию.

## ✅ Ожидаемый результат

Регистрация не выполняется.

Поле «Телефон» выделяется красным цветом и появляется сообщение о некорректно заполненном поле.

## 📎 Источник

Баг зарегистрирован в YouGile под ID **ETA-11** в рамках тестирования веб-приложения Hitch.
