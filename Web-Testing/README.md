# Web Testing

В этом разделе представлены примеры моей практики ручного и
функционального тестирования веб-приложений.

## Что представлено

- анализ требований;
- составление чек-листов;
- разработка тест-кейсов;
- функциональное тестирование;
- UI-проверки;
- позитивные и негативные сценарии;
- выявление и документирование дефектов.

## Учебные проекты

### Hitch — Web

В рамках проекта выполняла функциональное тестирование
веб-приложения, анализировала требования, составляла
чек-листы и тест-кейсы, проводила UI-проверки
и оформляла баг-репорты.

### EU-Relocate

Проводила ручное тестирование веб-приложения,
проверяла формы и пользовательские сценарии,
составляла тест-кейсы и документировала найденные дефекты.
