# Web Testing

В разделе представлены учебные проекты по ручному тестированию веб-приложений.

Основные направления практики: функциональное тестирование, UI-проверки, работа с тестовой документацией, позитивные и негативные сценарии, поиск и документирование дефектов.

## 📂 Проекты

### Hitch — Web

Учебный проект по ручному тестированию веб-приложения.

В рамках проекта выполнялись:

- анализ требований;
- функциональное тестирование;
- составление чек-листов;
- разработка тест-кейсов;
- позитивные и негативные проверки;
- UI-проверки;
- поиск и документирование дефектов.
