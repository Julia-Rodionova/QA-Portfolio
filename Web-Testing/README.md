# Web Testing

В разделе представлены учебные проекты по ручному тестированию веб-приложений.

Основные направления практики: функциональное тестирование, UI-проверки, работа с требованиями и тестовой документацией, позитивные и негативные сценарии, поиск и документирование дефектов.

## 📂 Проекты

### Hitch — Web

Учебный проект по ручному тестированию веб-приложения Hitch.

В рамках проекта выполнялись:

- анализ требований;
- разработка и выполнение тест-кейсов;
- функциональное тестирование;
- тестирование совместимости;
- Usability-тестирование;
- позитивные и негативные проверки;
- работа с матрицей трассировки;
- анализ покрытия требований;
- поиск и документирование дефектов;
- подготовка итогового отчёта о тестировании.

**Результаты проекта:**

- 154 тест-кейса;
- выполнение тест-кейсов — 98%;
- успешное прохождение — 77%;
- покрытие требований тест-кейсами — 100%;
- найдено 63 дефекта;
- исправлено 22 дефекта.

[Подробнее о проекте Hitch](Hitch-Web/README.md)
