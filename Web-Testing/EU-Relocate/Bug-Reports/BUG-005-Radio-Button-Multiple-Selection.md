# 🐞 BUG-005 — В вопросе «Ты хочешь на море?» можно выбрать два radio button одновременно

## Основная информация

| Поле | Значение |
|---|---|
| **Приоритет / серьёзность** | Высокий |
| **Статус** | Не указан в исходном баг-репорте |
| **Окружение** | Google Chrome Windows 10 |

## Шаги воспроизведения

1. Открыть сайт `https://htmlonelove.skillbox.cc/WDyw2yoPAZ/quiz.html`.
2. Выбрать 2 варианта ответа в radio button «Ты хочешь на море?».

## Фактический результат

Возможно выбрать 2 варианта.

## Ожидаемый результат

Нельзя выбрать 2 варианта.

## Вложения
