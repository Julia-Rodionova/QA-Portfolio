# 🐞 Bug Reports — EU-Relocate

В данном разделе представлены примеры дефектов, обнаруженных в ходе ручного тестирования веб-приложения **EU-Relocate**.

Для портфолио отобраны **6 показательных баг-репортов**, демонстрирующих работу с различными типами дефектов:

- валидацией данных;
- работой форм;
- сохранением выбранных значений;
- навигацией;
- интерактивными элементами;
- бизнес-логикой квиза.

Все баг-репорты доступны для просмотра непосредственно в GitHub.

## 🔍 Что проверялось

В процессе поиска и анализа дефектов проверялись:

- соответствие фактического поведения требованиям;
- валидация пользовательских данных;
- отправка форм;
- сохранение выбранных значений;
- навигация между страницами и разделами;
- работа интерактивных элементов;
- логика выбора вариантов ответа;
- формирование результата квиза.

---

## 🌍 Проверка бизнес-логики

Отдельное внимание уделялось странице **«Подобрать страну»**.

Результат квиза должен формироваться на основании ответов пользователя о:

- профессиональной сфере;
- регулярном ежемесячном доходе;
- желании жить у моря.

В ходе тестирования было выявлено несоответствие между ожидаемым и фактическим результатом работы алгоритма.

Пример:

[🐞 BUG-006 — Incorrect Country Quiz Result](BUG-006-Incorrect-Country-Quiz-Result.md)

Для данного дефекта также представлена **видеозапись воспроизведения**, которую можно посмотреть непосредственно внутри баг-репорта на GitHub.
