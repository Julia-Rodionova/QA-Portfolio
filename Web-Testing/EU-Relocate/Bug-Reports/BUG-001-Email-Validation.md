# 🐞 BUG-001 — Форма «Напишите нам» отправляется с невалидным E-mail

## Основная информация

| Поле | Значение |
|---|---|
| **Приоритет / серьёзность** | Critical |
| **Статус** | В работе |
| **Окружение** | Google Chrome 124.0.6367.208, Windows 10 |

## Шаги воспроизведения

1. Зайти на сайт `https://htmlonelove.skillbox.cc/avhusq2MvM/index.html`.
2. Перейти в футер страницы и нажать ссылку «Контакты».
3. На форме «Напишите нам» в поле «E-mail» ввести символы без `@` и точки (например, `testtest`).
4. Заполнить поля «Имя», «Телефон», «Тип вопроса», «Содержание вопроса» валидными значениями (например, `Олег`, `+79000000000`, `другое`, `тестовый вопрос`).
5. Нажать кнопку «Отправить».

## Фактический результат

Допускается отправка формы «Напишите нам» с невалидными значениями в поле «E-mail».

## Ожидаемый результат

Поле «E-mail» подсвечено красным, присутствует сообщение: «Пожалуйста, введите корректный email».

## Вложения

В исходном баг-репорте вложение не указано.
