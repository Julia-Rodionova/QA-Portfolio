# 🐞 BUG-002 — Не сохраняется выбранный тип вопроса при переключении на другое поле

## Основная информация

| Поле | Значение |
|---|---|
| **Приоритет / серьёзность** | Major |
| **Статус** | В работе |
| **Окружение** | Google Chrome 124.0.6367.208, Windows 10 |

## Шаги воспроизведения

1. Зайти на сайт `https://htmlonelove.skillbox.cc/avhusq2MvM/index.html`.
2. Перейти в футер страницы и нажать ссылку «Контакты».
3. На форме «Напишите нам» заполнить поле «Тип вопроса» любым значением из выпадающего списка.
4. Перейти на любое другое поле.

## Фактический результат

Не сохраняется выбранный тип вопроса на форме «Напишите нам» при переключении на другое поле.

## Ожидаемый результат

Выбранный тип вопроса сохраняется при переключении на другое поле.

В исходном баг-репорте вложение не указано.
