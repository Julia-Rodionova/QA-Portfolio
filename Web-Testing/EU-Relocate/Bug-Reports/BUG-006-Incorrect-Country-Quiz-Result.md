# 🐞 BUG-006 — Неверный результат квиза при выборе «Более 3 тыс. евро», «не IT», «есть море»

## Основная информация

| Поле | Значение |
|---|---|
| **Приоритет / серьёзность** | Высокий |
| **Статус** | Не указан в исходном баг-репорте |
| **Окружение** | Google Chrome Windows 10 |

## Шаги воспроизведения

1. Открыть сайт `https://htmlonelove.skillbox.cc/WDyw2yoPAZ/quiz.html`.
2. Заполнить ответы в форме:
   - сфера — `Нет`;
   - доход — `Более 3 тыс. евро`;
   - море — `Да`.
3. Нажать кнопку «Подобрать страну».
4. Дождаться результата.

## Фактический результат

Отображаются страны Испания, Венгрия, Лондон.

## Ожидаемый результат

Отображаются страны Португалия, Испания.
