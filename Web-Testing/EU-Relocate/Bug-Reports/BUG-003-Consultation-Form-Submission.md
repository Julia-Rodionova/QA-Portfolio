# 🐞 BUG-003 — Ошибка отправки формы «Получите бесплатную консультацию» с валидными данными

## Основная информация

| Поле | Значение |
|---|---|
| **Приоритет / серьёзность** | Major |
| **Статус** | Открыт |
| **Окружение** | Google Chrome |

## Шаги воспроизведения

1. Зайти на сайт `https://htmlonelove.skillbox.cc/WDyw2yoPAZ/index.html`.
2. Заполнить обязательные поля формы корректными значениями: «Имя» — `тест`, «E-mail» — `test@test.ru`, «Telegram или WhatsApp» — `+7-800-100-00-00`.
3. Нажать кнопку «Хочу консультацию».

## Фактический результат

Появляется всплывающее окно с текстом «Успешно. Ваша заявка отправлена», также высвечивается ошибка «Произошла ошибка отправки».

## Ожидаемый результат

Появляется всплывающее окно с текстом «Успешно. Ваша заявка отправлена».

## Вложения

В исходном баг-репорте вложение не указано.
