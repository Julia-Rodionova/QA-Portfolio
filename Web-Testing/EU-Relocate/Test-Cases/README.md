# 📝 Test Cases — EU-Relocate

В данном разделе представлены тест-кейсы, разработанные и выполненные в рамках ручного тестирования веб-приложения **EU-Relocate**.

Для удобства просмотра материалы представлены в двух форматах:

- **Markdown (`.md`)** — просмотр тест-кейсов непосредственно в GitHub;
- **Excel (`.xlsx`)** — исходная рабочая документация.

Всего в разделе представлено **49 тест-кейсов**:

- **31** — тестирование главной страницы;
- **18** — тестирование страницы «Подобрать страну».

---

## 🏠 Главная страница

Для главной страницы выполнен **31 тест-кейс**.

- заголовки и текстовые блоки;
- форма «Получите бесплатную консультацию»;
- позитивные и негативные сценарии отправки формы;
- валидация полей;
- ссылка «Политика конфиденциальности»;
- блок «Кому подойдёт программа»;
- блок «С чем поможем»;
- блок «Как это работает»;
- блок «Почему мы»;
- карточки гайдов;
- форма «Получить бесплатный гайд»;
- блок «Отзывы»;
- футер;
- ссылки и контакты.

## 🌍 Проверка бизнес-логики квиза

Особое внимание при тестировании страницы «Подобрать страну» уделялось бизнес-логике формирования результата.

Согласно требованиям, результат зависит от комбинации ответов пользователя:

- наличия образования или работы в IT, интернет-маркетинге или дизайне;
- регулярного ежемесячного дохода;
- желания жить у моря.

Тест-кейсы использовались для проверки различных комбинаций входных данных и соответствия полученного результата требованиям.

## 🐞 Работа с результатами

Для каждого выполненного тест-кейса фиксировались:
