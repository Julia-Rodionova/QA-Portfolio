# 📝 Test Cases — EU-Relocate

В данном разделе представлены тест-кейсы, разработанные и выполненные в рамках ручного тестирования веб-приложения **EU-Relocate**.

Тестирование проводилось на основе требований проекта и охватывало основные пользовательские сценарии, функциональность страниц, формы, навигацию и бизнес-логику приложения.

Набор содержит тест-кейсы для проверки главной страницы веб-приложения.

В рамках тестирования проверялись:

- элементы главной страницы;
- функциональность форм;
- навигация;
- ссылки;
- пользовательские сценарии;

- соответствие требованиям.

### 🌍 Страница «Подобрать страну»

Проверялись:

- отображение страницы;
- варианты ответов;
- выбор ответа пользователем;
- переход между вопросами;
- работа элементов управления;
- определение подходящих стран;
- соответствие результата выбранным параметрам;
- элементы навигации.

---

## 🌍 Проверка бизнес-логики квиза

Особое внимание уделялось логике определения подходящих стран.

Согласно требованиям, результат зависит от нескольких параметров:

- профессиональной сферы пользователя;
- регулярного ежемесячного дохода;
- желания жить у моря.

Тест-кейсы использовались для проверки различных комбинаций ответов и соответствующего результата.
