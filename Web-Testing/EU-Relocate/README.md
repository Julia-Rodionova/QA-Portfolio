# 🌍 EU-Relocate — Web Testing

Учебный проект по ручному тестированию веб-приложения **EU-Relocate**.

EU-Relocate — сервис, помогающий IT-специалистам с релокацией. Тестируемый сайт ориентирован на начинающих IT-специалистов и предназначен для знакомства пользователей с программами релокации и получения заявок на консультацию.

---

## 🎯 Цель проекта

Проверить соответствие веб-приложения требованиям, выявить и документировать дефекты, а также выполнить повторное и регрессионное тестирование после получения обратной связи от команды разработки.

В рамках проекта выполнялись:

- анализ требований;
- подготовка и корректировка тест-кейсов;
- функциональное тестирование;
- позитивное и негативное тестирование;
- тестирование форм;
- тестирование главной страницы;
- тестирование страницы «Подобрать страну»;
- регистрация дефектов;
- анализ отклонённых баг-репортов;
- повторное тестирование исправленных дефектов;
- регрессионное тестирование.

## 🔍 Протестированная функциональность

В рамках проекта тестировались:

### 📨 Форма «Напишите нам»

Проверялись:

- соответствие формы требованиям;
- корректность отображения;

- валидация данных;

- отправка незаполненной формы;

### 🏠 Главная страница

Проводилось функциональное и UI-тестирование элементов главной страницы, форм, навигации и ссылок.

### 🌍 Страница «Подобрать страну»

Проверялась работа квиза по подбору страны, включая:

- выбор вариантов ответа;
- переход между вопросами;
- логику определения подходящих стран;
- отображение результата;
- навигацию и элементы страницы.

### 🔄 Повторное и регрессионное тестирование

После получения результатов от команды разработки выполнялись:

- проверка исправлений;
- переоткрытие воспроизводящихся дефектов;
- регрессионное тестирование затронутой функциональности.
